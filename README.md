# household-income-planner

働き方（勤務日数・収入）を変更した場合に家計へ及ぼす影響を概算するシミュレーターです。

世帯主と配偶者のみが働いている世帯において、「本人（働き方を変える人）」と「配偶者（勤務形態が変わらない人）」の2人分の収入・支出を入力し、変更前・変更後の2つのシナリオを並べて比較します。

## 主な機能

- **変更前・変更後の比較**：本人の週あたり勤務日数・勤務時間・収入を変更前後で入力し、手取り収入や世帯収支への影響を比較
- **税・社会保険料の概算計算**：健康保険料・厚生年金・雇用保険料・所得税・住民税を概算計算（協会けんぽ東京都2024年度の料率を使用）
- **扶養判定**：103万円の壁（配偶者控除）・130万円の壁（社会保険の扶養）を判定。どちらが扶養に入る可能性があるかは「本人」「配偶者」のどちらでも選択可能
- **扶養家族（配偶者以外、主に子）**：人数を入力すると扶養控除を概算計算。控除を受ける側は「本人」「配偶者」のどちらでも選択可能
- **収入の入力方法**：月給＋賞与で入力する方法と、年収を一括で入力する方法を切り替え可能
- **生活費の分担方法**：割合で分担する方法と、どちらかが固定額を送金し残りを全負担する方法（送金方向は任意）を選択可能
- **入力内容の保存**：入力したパラメーターはブラウザのlocalStorageに自動保存され、リロードしても消えません。JSONファイルとしてエクスポート・インポートも可能

## 前提条件

このシミュレーターは以下を暗黙の前提としています。当てはまらない世帯では結果が実態とずれます。

- 世帯主と配偶者のみが働いている世帯（他の世帯員の収入・扶養は考慮しません）
- 本人・配偶者ともに会社員で、厚生年金・協会けんぽ（東京都2024年度の料率）に加入していること
- 扶養（103万円・130万円の壁）に入れるのは本人・配偶者のどちらか一方のみで、両者が同時に扶養に入るケースは考慮しません
- 扶養親族（配偶者以外、主に子）の扶養控除は、年齢区分（特定扶養親族・老人扶養親族・16歳未満）を考慮せず、一律38万円（所得税）・33万円（住民税）で概算します
- 住民税は前年所得に基づく概算で、実際の課税開始タイミングのズレは反映していません

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示されたURL（デフォルトは http://localhost:5173 ）にアクセスしてください。

### その他のコマンド

```bash
npm run build   # 型チェック＋本番ビルド
npm run preview # 本番ビルドのプレビュー
npm test        # テスト実行
npm run lint    # ESLint
```

## 免責事項

本シミュレーターは概算計算です。実際の税額・保険料は勤務先・お住まいの自治体・家族構成等により異なります。正確な計算には税理士等の専門家にご相談ください。
